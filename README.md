# Práctica Parcial · Marketing Táctico y Operativo (Unidad 3)

Práctica de multiple choice de nivel universitario para preparar el parcial.
Es un único archivo HTML autocontenido: se abre con doble clic, funciona sin internet.

## Cómo usar

Abrí [`Practica - Campanas de Comunicacion (Capriotti).html`](./Practica%20-%20Campanas%20de%20Comunicacion%20(Capriotti).html) en cualquier navegador.

En la pantalla de inicio elegís el texto a practicar:

- **Capriotti (2024) — Campañas de Comunicación** · 47 preguntas
- **Martí (2017) — Estrategias de Comunicación** · 40 preguntas

## Características

- Corrección detallada por pregunta: por qué la correcta es correcta, por qué falla cada distractor, referencia al texto y una regla práctica.
- Formatos variados: excepción, combinación (I-IV), todas/ninguna, comparación y aplicación.
- Dificultad predominantemente alta.
- Opciones de práctica: orden aleatorio de preguntas, mezcla de posición de las opciones y filtro por dificultad.
- Repaso de las preguntas falladas al terminar.
